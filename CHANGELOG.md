# Changelog

## 0.6.1 (2026-11-16)
- Fused sigma-clip passes: the final (weighted/unweighted) mean is accumulated in the last clipping pass, the survivor list is carried into the next iteration, and tile sums are accumulated during the gather. `testSinglePassSigmaClipEquivalence` proves bit-identical results against the old two-pass references; self-tests 210. `go test -bench` shows ~0.76–0.92 µs/op vs ~0.96–1.17 µs/op for the references (N=16, 2 iterations).
- Upgraded toolchain to go1.27.4 (`go 1.27` + pinned toolchain in both modules; CI/release updated). Full matrix green: gofmt, vet, 209 self-tests, `go test`, PureRaw CGO=0 + race, race build and six cross-build targets. BENCHMARKS re-baselined (4-frame native-CR2 sigma stack 39.031 s).
- Added `--comet-target PATH` ephemeris mode (ISO8601 `RA_deg Dec_deg`, linear interpolation by EXIF time; requires `--plate-solve`). Validation of RA/Dec ranges and clearer errors.
- Added `testCometEphemerisParse`; self-tests now 182.
- SIP order-2: applied in WCS helpers (`wcsTanForward`, `wcsTanInverseSIP`); stacking resampler remains affine/similarity-based (documented).
- Version bumped to 0.6.1; docs updated (README, TECHNICAL_SPEC, prompt-ai).
- Added `--fits` writer (`stacked_sum.fits`, big-endian BITPIX=-32, NAXIS=3) and round-trip selftest; self-tests 186.
- Added `--comet-ephem-strict-exif` to fail instead of falling back when a light lacks EXIF time; comet-target examples in README.
- Documented SIP stacking-resampler limitation and a reproducible OrionNebula grid-vs-real-flat validation protocol.
- Added `--bpm-auto` / `--bpm-auto-sigma` (bad-pixel map from master dark/bias) with `testBPMAuto`; self-tests 187.
- Wired `--plate-solve` into `--post-only` (re-detect stars from the stored float32 stack); `testPlateSolvePostOnlyNoStars` added; self-tests 188.
- Detected stars now carry a flux-weighted half-flux radius (HFR); `testStarHFR` added; self-tests 189.
- Added `--xisf` writer (monolithic XISF 1.0, planar Float32) with `testXISFWrite`; self-tests 190.
- Added `--hfr-quality` opt-in: median star HFR replaces blob size as FWHM proxy for frame quality; `testHFRQuality`; self-tests 191.
- Added `--sigma-clip-low` / `--sigma-clip-high` asymmetric MAD rejection; `testSigmaClipAsymmetric`; self-tests 192.
- Added `--annotate`: offline Gaia catalog projection onto the plate-solved stack, annotated JPEG, and `anomalies.json`; `testCatalogAnnotationSkip`; self-tests 193.
- Added `--starless`: starless + star-layer float32/JPEG outputs from the post-processing star-removal step; `testPipelineStarless`; self-tests 194.
- `--fits` now writes TAN WCS keywords (CRVAL/CRPIX/CD, degrees) when a plate solution is available.
- Hardened `--bpm-auto`: refuse maps flagging >0.1% of the sensor (avoids pathological thresholds on low-noise masters).
- Added `--json-report` (structured `report.json` alongside `report.txt`).
- `--fits`/`--xisf` now also write `stacked_mean.fits`/`stacked_mean.xisf` (linear mean stack, WCS in FITS).
- Added `--normalize-mode` (scale-offset/additive/multiplicative) with `testNormalizeModes`; self-tests 195.
- Added `--bg-multiscale` coarse percentile background before the polynomial fit; `testMultiscaleBackground`; self-tests 196.
- Added `--config FILE` JSON flag files (CLI overrides config); `testConfigFile`; self-tests 197.
- Added `--deconvolve` (Gaussian-PSF Richardson-Lucy) with `--deconv-sigma/-iters`; `testRichardsonLucy`; self-tests 198.
- Added `--narrowband HOO|SHO` with `--nb-a/--nb-b/--nb-c` mono stacks; `testNarrowband`; self-tests 199.
- Added `--resume` (reuse existing stack and continue with post-processing); `testResumeFromStack`; self-tests 200.
- Added `--drizzle-upsample/--drizzle-pixfrac` diagnostic drizzled upsample; `testDrizzleUpsample`; self-tests 201.
- Added `--normalize-per-channel` (independent RGB global normalization); `testNormalizePerChannel`; self-tests 202.
- Added `--wavesharp` classical multi-scale detail enhancement (BXT-like baseline from research §13); `testWaveSharpen`; self-tests 203.
- Default pipeline now logs and records reference-frame HFR (seeing proxy) in report notes; review in research §13.4.
- Added `testReferenceFITSSeed` (FITS RA/DEC plate-solve seed) and README links to BENCHMARKS/research; self-tests 204.
- Gemini outcome archived in `research/`; implemented scratch gradient-detrend retry for star detection (`testDetrendStarDetection`); self-tests 205.
- Implemented dark-frame series QA (reject >3-sigma median/hot-pixel outliers before master dark); `testCalibrationQA`; self-tests 206.
- Gaia TAP client retries HTTP 429 (queue full) with capped `Retry-After` instead of failing; `testGaiaQueryTile429Retry`; self-tests 207.
- Modularisation steps 3–4: tagged `PureRaw/v0.1.1` (v0.1.0 had a CR2 Probe offset bug), SkyStacker now imports the library and its duplicated `pr*` decoder was removed; E2E 1-light stack 7.5 s, selftests 209.
- Started modularisation: PureRaw module path changed to `github.com/computerphysicslab/skystacker/PureRaw`, root `go.work` added (gitignored); both modules green.
- Added finite-sample MAD scale correction for small stacks (N=3..30) with `testFiniteSampleMAD`; self-tests 209.
- Applied `go fix` modernizers (Go 1.26) to SkyStacker and PureRaw; added `testing/synctest` Gaia rate-limiter test (`go test ./...`); self-tests remain 208.
- Upgraded toolchain to go1.26.11 (go.mod `go 1.26`, pinned toolchain; CI/release workflows updated); SkyStacker and PureRaw test matrices green, baselines re-measured in BENCHMARKS.md.
- Built-in pure-Go CR2 decoder (lossless JPEG/SOF3 + bilinear Bayer demosaic); `--no-native-cr2` opts out; `testNativeCR2Decode`; self-tests 208.
