Current product state (do not re-implement)
-------------------------------------------
- --bpm, --export-masters, --self-flat (v1 registered and Phase-3 grid).
- Default recoverable calibration when no user masters exist: metadata
  pedestal and grid self-flat. Darks are not fabricated. --no-self-flat and
  --black-level off opt out.
- SER input (.ser expanded to #frame=N) and comet stacking: pixel (`--comet-center`/`--comet-rate`), RA/Dec rate (`--comet-radec`/`--comet-sky-rate-arcsec`) and ephemeris (`--comet-target`, optional `--comet-ephem-strict-exif`) require `--plate-solve` when using WCS/ephemerides; ephemeris uses EXIF times and linear interpolation (fallback to reference time if missing, unless strict).
- --reference-crop PATH warps lights into an external reference frame by
  star-pattern matching. Output size equals the reference. Single-frame
  crop works with --limit 1. Do not revert to the old "output must match
  input dimensions" assumption in the pass-1/pass-2 spill paths.
- Plate solving is wired; SIP order-2 is applied in WCS forward/inverse helpers (`wcsTanForward`/`wcsTanInverseSIP`) and, with `--resample-sip`, in the stacking resampler (undistort reference -> similarity/affine warp -> redistort source, using stored `plate_solution.json` SIP).
- `--fits` writes `stacked_sum.fits` (big-endian BITPIX=-32, NAXIS=3); `--xisf` writes `stacked_sum.xisf` (monolithic XISF 1.0, planar Float32); writer round-trip selftests cover both.
- `--bpm-auto` derives a bad-pixel map from master dark/bias (median + N*sigma*MAD, `--bpm-auto-sigma`, default 5); `testBPMAuto` verifies detection and masking.
- Self-flat Phase 4 done: grid model is the default (v1 `registered` kept for compatibility). Validated on Orion limit 20 with mean/median/sigma and `--no-register`; extrapolation+min<0.45 guard added; gamma-aware correction documented as out of scope for sRGB. Real flat validation deferred.
